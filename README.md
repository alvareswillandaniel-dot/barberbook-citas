## Descripción del Proyecto
**BarberBook** es una aplicación de escritorio desarrollada en Python para automatizar la administración y reserva de citas en **Destiny Studio Barbería**. Reemplaza el registro manual y mensajes dispersos, permitiendo agendar clientes, asignar servicios, evitar choques de horarios y consultar las citas programadas en tiempo real.

## Tecnologías Utilizadas
* **Python 3.x:** Lenguaje principal del sistema.
* **Tkinter (ttk):** Librería nativa de Python para la interfaz gráfica de usuario.
* **SQLite3:** Motor de base de datos relacional nativo para la persistencia local de citas.
